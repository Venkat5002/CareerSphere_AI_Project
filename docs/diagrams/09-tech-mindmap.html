How a request travels

  1. A student taps Learn Spring Boot on the Career Map, in a browser or in the Xcode or Android app.
  2. React calls /api/student/what-if through Axios, with the login JWT attached.
  3. Vite (in development) or the single Docker image (online) passes it to Spring Boot.
  4. Spring Security checks the token and the STUDENT role; the controller calls MatchService.
  5. Hibernate loads the profile and open jobs from MySQL; the weighted score is recomputed for every job.
  6. The answer returns as JSON, and the jobs that cross 70% slide inside the ring on the SVG map.
